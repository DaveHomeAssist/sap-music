# Erosyn Artist Asset Pack

This is the reusable artist-facing pack for Erosyn, formerly SAP. It organizes the generated brand assets by real production use instead of export batch structure.

## Start Here

- Open `brand.html` for the interactive brand guide.
- Open `MANIFEST.csv` for a file-by-file asset map.
- Use `00-start-here/erosyn-asset-contact-sheet-v01.jpg` for a quick visual scan.
- Use `01-logos/png/` for immediate layout tests.
- Use `02-press-kit/one-sheet/erosyn-one-sheet-press-v01.pdf` for booking and press context.

## Folder Map

| Folder | Use |
|---|---|
| `00-start-here` | Quick scan assets and handoff notes |
| `01-logos` | PNG logo exports and SVG trace starters |
| `02-press-kit` | Press photos, source references, one-sheet PDF/PNG |
| `03-social` | Avatar, banners, posts, stories |
| `04-release-art` | Cover backgrounds and release templates |
| `05-live-visuals` | Flyers, stage screens, VJ stills |
| `06-web-digital` | CSS tokens and reusable web/digital references |
| `07-source-selects` | Clean source imagery for future design work |
| `08-brand-docs` | Copy, usage, rollout, sonic, EPK, and prompt docs |

## Production Notes

- Treat Erosyn as the public name. SAP should appear only as transition context.
- The PNG logos are useful for layout and social tests.
- The SVG logos are trace starters and should be hand-cleaned before final commercial logo lock.
- Keep the system dark, red, physical, and legible. Do not let glow effects replace basic hierarchy.
- Keep final contact links, booking email, DSP links, and social URLs outside this v01 pack until confirmed.
