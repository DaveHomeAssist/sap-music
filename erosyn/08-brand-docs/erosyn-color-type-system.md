# 🎨 Erosyn Color and Type System

- Palette is built around black, signal red, bone white, static gray, and deep blood red.
- Typography support should stay industrial, condensed, and readable.
- The wordmark carries the gothic identity. Body and layout fonts should stay clean.

---

## 🔴 Palette

| Role | Name | HEX | Use |
|---|---|---|---|
| Primary dark | Void Black | `#050505` | Backgrounds, posters, profiles |
| Primary accent | Signal Red | `#ff1b1b` | Glow, CTAs, signal marks |
| Deep accent | Bloodline Red | `#9e0018` | Shadows, gradients, secondary art |
| Light text | Bone White | `#f4efe7` | Text, flat logos |
| Neutral | Static Gray | `#8a8a8a` | Captions, metadata, secondary text |
| Utility | Warning Amber | `#ff9b2f` | Rare accent only |

---

## 🔠 Type Direction

| Use | Direction |
|---|---|
| Primary logo | Gothic blackletter wordmark |
| Icon | Cropped E/sigil from wordmark |
| Headers | Condensed industrial sans or bold geometric sans |
| Body | Clean system sans |
| Metadata | Mono or narrow sans |
