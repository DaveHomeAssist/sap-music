# 💿 Erosyn Cover Art Rules

- Use the waveform tear as the first primary release system.
- Use the warehouse smoke direction for EPs, live visuals, and EPK sections.
- Use synth/static visuals for studio content, mixes, and production clips.

---

## ✅ Production Rules

- Export final square covers at 3000 x 3000 px.
- Add final track titles manually in layout software.
- Do not use generated text inside the artwork background.
- Keep the logo flat or lightly glowing depending on contrast.
- Keep SAP out of final artwork except transition-specific posts.
