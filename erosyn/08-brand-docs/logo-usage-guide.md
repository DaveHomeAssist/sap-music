# 🖤 Erosyn Logo Usage Guide

- Use the full wordmark for banners, covers, stage screens, and EPK pages.
- Use the icon for avatars, thumbnails, favicons, and small profile spaces.
- The SVG files are starter traces from the draft concept. Hand-clean them before final commercial lockup.

---

## ✅ Rules

- Keep generous padding around the wordmark.
- Use flat versions for print, EPK, and legibility tests.
- Use glow versions only when the background is dark and low detail.
- Do not place the full wordmark in tiny circular avatars.
- Do not use AI-generated text as a final logo source without vector cleanup.
